## 본문 구성과 검토 범위

본문은 **공통 준비 / 일반 플레이 / 스페셜 시나리오**로 재편한다. 일반 플레이는 **임포트·익스포트 / 전투 / 거주**, 스페셜은 **미개척·오지 차원계(개척·특수 IO) / 장기거주 / 플라잉(2중 차원이동) / 드랍아웃**으로 묶는다. 통상 진입·이탈은 공통 준비의 캠페인 기본 IO로 처리하고, IO 자체가 사건이 되는 상세 처리는 스페셜에 둔다. 에고의 장기 체류·유지·회복은 장기거주 섹션에 둔다. IO의 사용자 정의는 물질계 상태·진입 방식/유형/조건·차원 캐릭터 신규/이전/구성·이탈 시 소멸/보관이다. IO의 실제 규약은 **특정 월드·캠페인 세팅**에 속한다. **파이오니아 타입별로 IO를 분류**하며 첫 명칭은 **신성인공계IO**다. 같은 타입의 기본 IO를 참조하고 차원별 현지 예외·호환을 확인한다. 코어는 처리 틀을 제공하고 캠페인은 실제 프로필을 지정한다. 사물·정보·권한의 반입/반출과의 편집 경계를 정리한다.

**일반 전투의 최신 기준:** 차원 안에서도 공통 사이버펑크 전투를 적용하고 현지 환경·몸·장비 조건을 반영한다. 높은 근접 화력과 필수적인 총기전을 대략 반반으로 활용하며 프로젝타일·레이저 방어를 구분해 설계한다. 본체/연결 공격·반동은 명시된 특수 효과다.

**드랍아웃의 최신 정의:** 해당 차원계에 다시 들어갈 수 없게 되는 대가. 이를 감수하는 자폭 시나리오를 스페셜에 포함한다. 기존 코마·은퇴 중심 설명은 정정 대조 대상으로 남기고, 제5판은 이번 사용자 설명을 우선한다.
