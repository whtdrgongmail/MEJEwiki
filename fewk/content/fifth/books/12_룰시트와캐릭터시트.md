이 양식은 인물·몸·차원과 실제 행동의 결과를 어디에 기록하는지 정합니다. 입문 HP·장비·회복·성장은 Core의P-INTRO-01, 장기거주 체류는SPL-RES-01을 참조합니다. 코핀 수신/지원, 통합 인터랙션·장치/몸 시술·노출/기록 격리, 운송/시간 이동·도안/선박의 채운 기록도 해당 절에 있습니다. 인물의 배운 숙련과 각 몸의 상태는 시트를 교체해도 이어갑니다. 아래에서 이번 장면에 쓰는 양식을 찾습니다.

구판6능력치·직업 레벨·파생 자원표를 먼저 채우는 방식으로 시작하지 않습니다. **인물의 삶/목표와 배운 기술 → 쓸 몸 → 차원의 생활/물리·IO → 사건의 조건/결과** 순서로 작성합니다. 경쟁과 방어는 Core의 한 성공 수준/동률 비교 규약을 쓰고, 서술 권한과 적용 대상이 결과를 정합니다.

완성된PC는 [러너12인](14_레디메이드_러너.md), 해당 시트로 시작하는 사건은 [표준 튜터리얼6편](15_표준튜터리얼_시나리오.md)에 있습니다. 장면 머리에는 현재 몸/HP·위치/IC시각·행동·다음 약속만 요약하고, 상세 장비는 변경할 때 갱신합니다.

### 첫 장면에 복사할 시작 양식

먼저 진행자가 사용할 차원·기본 IO·지급 장비와 첫 사건을 준비합니다. 참가자는 아래 양식을 복사해 인물과 현재 몸을 적습니다. 이 시작 양식을 쓰면 **같은 인물/몸ID의 원본 기록**으로 삼고, 필요한 상세 항목만 아래1~5절과 연결합니다. 같은 잔량을 두 양식에서 따로 갱신하지 않습니다. 특수 기능을 사용할 때는 해당 인터랙션 규격을 연결합니다.

```text
인물ID / 이름 / 직업·전문:
하고 싶은 일 / 지키고 싶은 일상 / 동료와 함께할 이유:
생성의 형성 이력: 해당하면 매팅·샤이닝 등 / 실제 얻은 기능·조건:
생활·지식의 전문 범위 / 선택한 프리셋 또는 직접 배분:
내 감정·관계 / 함께 열고 싶은 장면·참여 범위:

물질계 본체ID·위치·보호 / 본체 상태·HP:
현재 활성 몸ID·차원·위치 / 상태·HP·저항·이동:
현재 몸의 장비ID·기능·장갑 / 탄약·셀·방호 유형/충전:
처치 효과 사용 / 마지막 휴식·거점 회복 구간:
이번에 사용할 인터랙션 / 참조 숙련 / 현재 몸·수단·권한 / 시간·비용·결과:

차원 룰시트·IO / 진입 완료 여부·귀환 수신장소·경로/지원 담당:
보관 몸ID·자리 / 보관할 손상·잔량 / 해당 차원 재진입 제한:
장면ID·IC 시점 / 상태 버전 / 진행·확정 담당 / 실제 응답 약속:
이번 목표·방법 / 필요한 경우 최종 목표·좋은·탁월 / 예고한 결과:
이번 라운드의 남은 이동·주요 행동·개인 반응 / 현재 몸의 방호 사용:
실제 실행·굴림/무판정 / 받은 정보·쓸 물건·변경한 몸 / 다음 선택:
```

입문 표준 몸을 사용하는 캠페인은 HP12·육체 저항50·이동10m에서 시작합니다. 라운드5초의 주요 행동1회·개인 반응1회와 실제 남은 이동을 이어 쓰고, 몸을 바꿨다고 행동을 새로 받지 않습니다. 이미 진행한 장면이면 시작값을 덮어쓰지 않고 마지막 확정 손상/잔량을 옮깁니다. 활성 몸은 하나이며 본체와 현지 몸의 HP·설치 장치는 따로 기록합니다.

#### 바로 고를 숙련 배분

세 프리셋은 [Core 생성](10_CoreRulebook.md#fewk-make)의 배분과 같습니다. 하나를 골라 한 사람의12개 숙련으로 복사하거나 같은70 두 개·50 세 개·30 네 개·10 세 개를 직접 배분합니다. 직업·전문과 허용 기능은 캠페인에서 정합니다.

| 숙련 | 현장 러너 | 자료 러너 | 생활 중개자 |
|---|---:|---:|---:|
| 격투 | 70 | 30 | 10 |
| 사격 | 70 | 30 | 10 |
| 운동 | 50 | 10 | 30 |
| 은밀 | 50 | 30 | 30 |
| 관찰 | 50 | 50 | 50 |
| 조사 | 30 | 70 | 50 |
| 해킹 | 10 | 70 | 10 |
| 공학 | 30 | 50 | 30 |
| 의학 | 30 | 10 | 30 |
| 교섭 | 30 | 30 | 70 |
| 생활 | 10 | 10 | 70 |
| 지식 | 10 | 50 | 50 |

상황 보정이 없을 때70은 `70/35/14`,50은 `50/25/10`,30은 `30/15/6`,10은 `10/5/2`입니다. 숫자는 최종 목표/좋은 성공의 상한/탁월한 성공의 상한입니다. 상황이 바뀌면 보정 후 최종값에서 다시 계산합니다. 안전한 만남은 이 값을 굴리지 않고 이어갑니다.

**장비는 선택한 캠페인의 지급표에서 적습니다.** Core의 일반 지급 예와 입문 시나리오의 계약 지급은 서로 다른 준비입니다. [신성의 카드](13_입문시나리오.md)에서는 그 시나리오1절의 개인/팀 장비를 사용합니다. 자료 러너·생활 중개자에게도 지정한 방호/권총이 있는 경우를 일반 프리셋의 자동 장비로 바꾸지 않습니다.

거주 장면은 현재 장소와 하고 싶은 일부터 시작할 수 있습니다. 반입/반출은 실제 대상/권한/수신자를, 전투는 현재 거리/사선과 몸/잔량을 추가합니다. [이지룰](01_텀블벅_이지룰_초안.md)·[입문 사건](13_입문시나리오.md)으로 시작하고, 진행자는 [실제 참가자 시험 순서](#fewk-human-trials)를 사용할 수 있습니다.

### 사용할 인터랙션 — 같은 목록에서 찾기

숙련표는 백분율 값을 준비하는 표입니다. 아래는 그 값을 사용해 **지금 할 수 있는 행동**을 찾는 목록입니다. 일반 행동과 고유 기능을 함께 적고, 동일한 숙련값을 항목마다 다시 배분하지 않습니다. 능력·현화 효과·기술·임플란트 기능을 인터랙션의 획득 경로와 사용 조건으로 구분하고, 매팅·샤이닝은 위 생성 이력에 기록합니다. 리듬필러는 직업·전문에, 실제 전조 감지는 이 행동 목록에 적습니다. 상시 기능은 해당 몸/장치에 연결하며 불확실한 장애가 있을 때 참조 숙련으로 판정합니다. 상세 규격은 해당 인터랙션/장비 프로필을 참조합니다.

| 인터랙션 이름 | 참조 숙련/준비값 | 몸·도구·권한 등 사용 조건 | 행동·비용·효과 규격 | 획득 경로 |
|---|---|---|---|---|
| 권총 사격 | 사격 /  | 현재 몸의 조작·권총·탄약·사선 | 해당 무기 프로필 | 훈련·장비 |
| 시스템 접속/잠금 해제 | 해킹 /  | 인터페이스·연결·목표 권한/장애 | 해당 시스템과 공통 판정 | 학습·임플란트/도구 |
|  |  |  |  |  |

연락·대화·안전한 일상은 이 목록을 모두 채워야 할 수 있는 허가제가 아닙니다. 특정 장치와 전문 기술처럼 조건이 중요한 행동을 기록하고, 무판정 행동은 실제 시간/상태만 변경합니다. [15절](12_룰시트와캐릭터시트.md)의 세 시험은 같은 목록에 넣을 상세 예입니다.

## 2. 몸 시트 — 지금 무엇으로 행동하는가

### 채워진 한 행동 — 예시와 실제 로그를 구분하기

다음은 [Core의 가상 대본](10_CoreRulebook.md#fewk-reading-example)을 같은 기록으로 옮긴 **작성 예**입니다. 실제 참가자 제출이나 시험 결과가 아닙니다. 캠페인 IO로 이미 진입했고 공개 기록을 읽을 수 있는 몸/단말을 갖춘 상태에서 시작합니다.

```text
장면: CAFE-READ / 사건 담당자: 예시 진행자
인물·활성 몸: P-READ / B-READ
참조 상태: 예시 v12 / 현지 IC 시각 t0
목표: 마지막 점검 담당자와 시각을 확인한다.
인터랙션: 접수증·공개 예약 대조 / 참조 숙련: 조사50
성립 조건: 접수증 보유, 읽을 수 있는 예약 기록과 사용 가능한 단말
도움: 담당자가 실제 대조 자료를 제공하여 조건 개선
준비값50 / 몸·장비 지속 보정0 / 상황 유리+20
최종 목표70 / 좋은35 / 탁월14
절차: 백분율 일반 판정 / 이번 사용 시간: 현지5초
예고한 성공: 지정 담당자·시각 확인 / 실패: 이번 시도에서 미확인
굴림62 / 결과: 성공 / 획득 정보: 지정 담당자·시각
상태 변경 제안: 정보 획득과 현지 t0+5초
담당자 확정 조건: v12의 관련 상태와 시간·자료·권한 충돌 확인
조건을 만족한 예시 확정 상태: v13 / 현지 t0+5초
유지: 본체·현지 몸HP, 탄약·충전·에고, 재진입 제한
남은 선택: 실제 담당자에게 연락할지, 동료와 다음 행동을 정할지
OOC 대기: 현지 시간/에고로 환산하지 않는다.
```

공개 기록에 없던 이름과 시각을 작성자가 임의로 더하지 않습니다. 이 예의 실제 필드는 캠페인 담당자가 미리 지정한 자료에서 받습니다. 관련 상태가 이미 바뀌었다면 v13을 자동 확정하지 않고 현재 자료와 미결정 행동을 대조합니다. 대조 성공은 다른 로그에서 진행 중인 정비나 귀환을 완료하는 효과가 아닙니다. [온라인 기록과 정정](#fewk-online-sheet)을 함께 사용합니다.

### 작은 작성 예 — 같은 사람을 이어서 쓰기

| 기록 | 물질계 | 현지 차원 |
|---|---|---|
| 인물 | `P-DEMO`, 공유 해킹70 | 같은 `P-DEMO` |
| 몸 | `B-BASE`, 육체 저항60 | `B-LOCAL`, 육체 저항40 |
| 해킹의 준비값 | 접근 장비가 있으면70 | 현지 인터페이스가 있으면70 |
| 불리한 해킹 | `50 / 25 / 10` | 같은 백분율 방식 |
| 본체반동 | 본체60으로 처리 | 현지40을 대신 쓰지 않음 |
| 일반 총격 | 본체가 피격 대상이면 본체 손상 | 현지 피격이면 현지 손상 |
| 이탈·저장 | 본체 상태를 확인 | IO의 보관 ID에 현지 몸 상태 기록 |
| 재진입 | 이전 기록 확인 | 드랍아웃 표시가 있으면 그 차원 재진입 불가 |

## 6. 채워진 입문 기록 — 생활 중개자와 두 몸

### 채워진 스페셜 승계 예

`P-03`이 시험A/B에서 플라잉을 합니다. 출발 몸B0는 물질계HP12, 중간 몸B1은A의 송신 거점HP9, 현재 몸B2는B의 자료실HP12입니다. L1/L2는 정상이며 시간은1:1, H는A2400시간·B240시간입니다. 같은2시간의 후보 감소는0.025와0.25이므로 공유 에고10→9.75입니다. 사격·교섭 등 숙련은 같은P-03을 참조하며 세 번 행동하지 않습니다.

안전한L2로B2→B1에 돌아오면B2의HP12/쓴 물품을 보관하고B1의HP9를 읽습니다. B1의HP가 본체12로 덮이지 않습니다. L1로 본체에 귀환해1시간 정상 회복하면 에고는10을 넘지 않습니다. 별도 비상 경로가 없는데L1이 끊겼다면 ‘본체 복귀 완료’로 적지 않고 사용 가능한 구조/경로를 찾습니다.

다음 작전에서`TEST-DROP`의 결행 전에 사본`COPY-03`을 승인된 수신자에게 전송했습니다. 준비된 폐기 장치가 작동하면 현지 몸/남긴 장비 소실과`P-03:TEST-DROP 재진입 불가`를 기록합니다. 본체HP12와 공유 숙련, 다른 차원A/B의 진입권은 그대로입니다. 사본`COPY-03`은 이미 도착했지만 남긴 공방 물품은 밖에 생기지 않습니다. 다음 생활 장면은 돌아오지 못할 현지의 이웃과 어떻게 연락할지를 다룰 수 있습니다.

이 사례의A/B·P-03·작전 장치는 시트 작성용 창작입니다. 실제 원전 차원의 공통 IO로 승격하지 않습니다. [스페셜 수치/경계 검사](검증/스페셜_검증결과.json)는 승계 조건을 확인하며 실제 참가자의 작성 성공을 뜻하지 않습니다.

거점의 출구가 닫혀도 이 시험의 수신은 유지될 수 있습니다. 그때 귀환 기록에는B-C0의 현재 위치와 `거점 외부 탈출 미해결`을 남깁니다. 지원자에게 연락하거나 실제 탈출 방법/협상 조건을 해결한 뒤 갱신하며, 저장된 현지 몸을 새 활성 인물처럼 추가 행동시키지 않습니다.

| 경로 단절 / 수신 장치 고장 | 각각의 위치·확인 시각·확인자와 고장 부위를 기록; 실제 복구 방법/담당자 준비 |

### 같은 IO, 두 차원 기록 — CAMP-COF-TEST 확장 예

아래는 같은 인물P-C1·본체B-C0·IO-COF-TEST를 쓰는 **신규 시험 예**입니다. 위 기본 장비의 보관슬롯1개와 구별하여, 이번에는 지원 슬롯2개·구성4회분·첫 방문 앰플2개를 미리 조달합니다. TEST-COF-B는 별도 허가/뇌네 지원을 확인한 개척 차원이며B-C2에는 권총을 지급하지 않고 현지 방호 충전1을 지급합니다. 정식 파이오니아 타입이나 모든 코핀의 용량을 확정한 표가 아닙니다.

| 버전/완료한 이동 | 활성 몸 / 보관 몸 | 공유 구성분/앰플 | 개인 방문 완료 |

S-UTILITY-01에서 POWER-S1이2000셀일 때 물체 이동과 발사를 각1번 실행하면1500셀입니다. 이 사이에 장전 주요 행동1회를 씁니다. 물체 이동 실패와 발사 실패도 작동한250셀을 소비하며 탄두는 발사 때 소모합니다. 신규 투사체를 만들지 않고 기존 물체 ID·위치·장전을 추적합니다. 사선 밖·점유/고정 물체는 시험 이동 대상이 아닙니다. 실제 분해·무장해제 모델이 추가되면 같은 인터랙션 형식으로 작성합니다.

후속FOLLOWUP-01은 승인 미확인·현지 실제300초 경과·기록원P-G1/B-G1의 현장/정상 단말/계정·망·담당자 연락/주요 행동 확보가 조건입니다. 실제120초 뒤 상태를 저장하고 OOC 이틀 보류해도120초입니다. 재개 후 실제180초가 지나 조건을 확인하면 주요 행동1·5초로 재확인을 요청할 수 있습니다. 승인이 이미 확인됐으면 종료하고, 망이 없으면 메시지를 보내지 않습니다. 제출 전의 단순 제안과 실제 송신을 구분하며 같은FOLLOWUP-01은 한 번만 적용합니다.

재개/종료에는 요청의 실제 송신 여부와 남은 행동/시간, 영수증을 받은 주체, 정정된 의심, 지워지지 않은CAM-01·물건 위치/몸 상태를 남깁니다. 실제 참가자 자료가 없으면 그 칸은 미확보로 적습니다. 구판의 날짜/가명/3시간 예시를 참가자 기록으로 대체하지 않습니다.

### 실제 참가자 시험 — 설명을 읽는 일과 플레이한 결과를 구분하기

이 절은 실제 참가자와 사용할 **시험 절차**입니다. 결과는 [입문 시나리오의 실제 시험 기록](13_입문시나리오.md)에 한 시험ID로 남기고 [완료 관문](검증/완료_관문.json)에 근거를 연결합니다. 참가자에게 건네는 시작 자료는 이지룰·위 시작 양식·선택한 사건의 공개 의뢰/자료입니다. 진행자의 진실과 아래 해설은 진행자에게 둡니다. 함께 같은 문서를 읽고 답을 확인한 것은 독립 독해와 구분해 기록합니다.

#### R. 처음 읽고 인물을 작성하기

새 독자는 이지룰과 시작 양식으로 자신이 플레이할 사람을 만듭니다. 인물/몸/차원·형성 이력/직업/인터랙션/스킬을 자기 말로 설명하고, 선택한 숙련·실제 장비와 활성 몸을 적습니다. 진행자는 처음부터 정답을 설명하지 않고 실제 시작/완료 시각, 찾아 펼친 위치, 첫 답변과 질문·도움을 기록합니다. 다음 다섯 과제는 독해 연습이며 캠페인의 실제 행동 결과가 아닙니다.

| 과제 | 참가자에게 묻거나 맡길 일 |
|---|---|
| R1 | 샤이닝을 겪은 리듬필러가 전조를 감지한다. 형성 이력·직업·인터랙션·참조 스킬·필요한 몸 조건을 구분해 적기 |
| R2 | 준비값70인 행동에 불리−20이 하나 있고 굴림25가 나왔다. 최종 목표·좋은/탁월 상한과 결과를 적기 |
| R3 | 해킹70인 인물의 필요한 단말이 물질계 본체에만 있다. 장비 없는 현지 몸에서 지금 같은 접속을 할 수 있는지와 필요한 준비를 설명하기 |
| R4 | 현지 몸을 HP5·탄약3·방호0으로 보관했다. 다음 호출 때 적을 몸 상태와 그대로 남는 인물 숙련을 작성하기 |
| R5 | 공학 작업을120/300초 진행한 상태에서 현실의 하루 동안 답을 기다렸다. 다음 로그의 작업 진행과 누가 감정·관계 선택을 작성할지 설명하기 |

첫 답과 해설 후 고친 답을 각각 남깁니다. 정답을 들은 뒤의 성공을 혼자 이해한 결과로 합산하지 않습니다. 오답이 생긴 문장/표를 찾아 수정하고 새로 읽는 사람 또는 별도의 미공개 과제로 재확인합니다. ‘몇 분 안에 작성’ 같은 시간 제한을 새 합격 기준으로 강요하지 않고 실제 소요를 측정합니다.

R1: 샤이닝은 형성 이력, 리듬필러는 직업/허용 전문, 전조 감지는 인터랙션, 관찰은 참조 스킬입니다. 캠페인이 허용한 감각과 이를 지원하는 현재 몸·실제 대상이 필요합니다. 이름만으로 새 기능이나 관찰70을 지급하지 않습니다.

#### P. 실제 사건·전투·거주를 운영하기

[신성의 카드](13_입문시나리오.md)의 준비·장면A~D를 실제 참가자가 선택하여 진행합니다. 의뢰/관계 동기, 정보 취득·접근 방법, 자료의 실제 수신, 귀환/보관과 다음 생활을 기록합니다. 열린 방법과 철수도 결과이며, 어떤 선택이 나올지 진행자가 미리 작성한 대본을 참가자 로그로 쓰지 않습니다. 선택하지 않은 경로는 ‘이번 시험에서 사용하지 않음’으로 남깁니다.

전투를 택했다면 근접/총격 시도·접근/엄폐·반응·방호·탄약과 한 라운드의 실제 행동을 기록합니다. 전투를 피한 팀은 그 사건을 협상/반출/거주 시험으로 남깁니다. **근접과 총격의 실제 검증이 빠졌다면 별도 시험ID의 전투 연습을 진행**합니다. 시나리오 장면C의 준비된 몸·장비·경비·배치와 같은 코어를 사용하고, 본편의 협상 결과를 취소하지 않습니다. 연습에서 다룬 선택/라운드만 검증 범위로 기록합니다.

마친 뒤 각 참가자가 ‘이 세계에서 계속 살고 싶은 이유/사람/장소’, ‘다음에 열고 싶은 생활’, ‘불필요하게 느낀 판정/참조’를 자기 말로 적습니다. FEWK의 매력·몸/차원 이동의 이해와 전투/비전투 역할을 실제 발언에 연결합니다. 승패나 성공 횟수만으로 재미와 난도를 판정하지 않습니다.

#### A. 실제 비동기 로그와 복귀를 운영하기

참가자와 담당자가 실제로 글을 주고받으며 [23절](#fewk-sheet-23)의 같은 인물·병행 로그를 사용합니다. 시작 조건으로 제시한120/300초의 작업·이미 쓴 부품, 현재HP/잔량을 확인한 뒤 같은 상태 버전을 읽은 제안을 접수합니다. 관련 변경을 대조해 확정하고, 응답 보류와 실제 복귀 뒤 남은 작업/선택을 이어갑니다. 이미 정당하게 아는 연락처 등록과 새 정보의 실제 송신/수신도 구분합니다.

실제 게시/답변 시각·합의한 응답 창, 로그ID·읽은/확정 버전·실행한 IC시간과 자원, 질문/정정·누가 복귀 요약을 읽고 이어갔는지를 보존합니다. 현실의 하루나7일을 가상으로 넣은 대본은 비동기 운영 증거가 아닙니다. 같은 자리에서 즉시 전개한 것은 실시간 연습으로 적고 실제 비동기 결과와 구분합니다. 기다림 자체로HP·에고·관계·작업 진행을 바꾸지 않습니다.

#### T. 타롯 선택·대기·백분율 대안을 비교하기

사용에 합의한 실제 참가자와 [TAR-P-02](02_타롯_해킹과_지능전_초안.md)를 운영합니다. 제출/공개·정보 잠금·교환별 행동·종료 효과와 다른 참가자의 같은 라운드 행동을 기록합니다. 참가자가 선택 이유·막힌 규칙·손패 고민/공개 대기·다시 쓰고 싶은지 말하게 하고 실제 시간을 남깁니다. 자동 모의 대결의 전략/승률을 참가자의 재미로 옮겨 적지 않습니다.

백분율과 비교하려면 같은 시작 조건을 복사한 **별도 비교 장면**에서 모드별로 한 번씩 진행합니다. 본편의 같은 목표를 타롯 후 백분율로 다시 굴리는 것이 아닙니다. 모드 순서·이미 알고 있던 정보와 참가 경험을 적고, 한 팀의 선호를 모든 커뮤의 선호로 일반화하지 않습니다. 비동기 타롯을 시험했다면 실제 제출/대기 로그도A와 같은 기준으로 남깁니다.

#### 근거를 제출하고 수정하기

```text
시험ID / R·P·A·T 중 실제 진행한 범위 / 날짜·참가자 수·경험:
사용한 이지룰·시트·사건·코어·타롯의 버전과 SHA256:
실제 작성/플레이/게시 로그 위치·행동 시각 / 확인자·공유 범위:
첫 답·실제 선택·멈춘 문장 / 설명을 받은 시점 / 참가자의 표현:
확인한 오류·영향받은 인물/몸/정보/시간 / 아직 다루지 않은 부분:

```

공유할 수 있는 가명과 발췌 범위로 근거를 연결할 수 있습니다. 실제 참가 자료가 없으면 결과 칸은 ‘미확보’로 둡니다. 제출 자료와 사용 버전·실행/발언의 연결이 확인되고, 발견한 규칙 오류/혼동을 수정·재확인한 뒤 해당 범위의 관문을 판단합니다. 읽기 양식 준비나 진행자의 단독 연습만으로 G7을 통과시키지 않습니다.

**채워진 예 — 공연 전에 연결을 고치는 러너들(신규 장면):** 카페에 맡긴 현지 몸과 악기/수리 부품을 기록했다. 현지 담당자는 허가받은 고장 연결과 실제 도안을 확인해 공학 인터랙션을 준비하고, 물질계의 동료는 그릇 보관 상태만 확인한다. 현지 조사 결과는 실제 연락이 도착한 시점에 동료의 IC 정보가 된다. 연락 대기는 현지에서 보낸 실제 시간과 OOC 게시 대기를 나누고, 같은 몸의 행동/자원을 중복 반영하지 않는다. 수리가 끝나면 실제 인계·지급과 몸 상태를 남겨 공연이나 식사 장면으로 이어간다. 다른 참가자가 대신 행동/동의를 제출했다는 기록을 만들지 않는다.

**숫자가 있는 정산 예:** 소설002의 보수80오얏과 이자50오얏만 사용하는 비교 예에서는 원금 감소분이30오얏이다. 실제 다른 비용이 있다면 해당 지출을 따로 기록한다. 이 비교는 모든 카페의 보수/금리나 PC 의지 담보 효과를 정하는 규칙이 아니다.

## 후속 검토 양식의 지위

21절의 R/P/A/T는 실제 참가자 시험을 할 때 사용할 양식입니다. 이번 원고 마감에서는 시험을 수행하지 않았습니다. 수치/상태 검산은 작성된 프로필만 확인하며 참가자의 이해·재미·커뮤 선호를 증명하지 않습니다. 새로운 고유 기술과 외부 플랫폼을 사용할 때는 해당 조건과 호환을 준비합니다.
