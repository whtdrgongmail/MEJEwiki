# FEWK 제5판 아트워크 제작목록 — 기본100장, 확장120장

**기본 제작 범위는 서로 다른 원화100장입니다.** 두 권의 표지·속표지·본문, 튜터리얼6편, 러너12인의 대표 포즈, 동백국과 열 대사국·길드 문장, 기본 굿즈를 갖출 수 있습니다. 실등신 대표 포즈를 그대로 키링에 쓰면100장으로 충분합니다. 별도 SD 키링12종까지 만들면112장, 주요 로어 인물8종을 더하면120장입니다.

장별 가로 이미지는 **World77장에 원화12종, Core독자 본문10개 큰 섹션에 원화8종**을 배치합니다. 같은 원화에서 다른 부분을 쓰고 제목·문장을 얹어 각 장의 가로 타이틀을 만듭니다. 이는 각 장에 전혀 다른 삽화가87장 있다는 뜻은 아닙니다. 모든 장의 가로 타이틀을 독립 원화로 만들려면 기본안에67장이 추가되어 **167장**, SD와 로어 인물까지 포함하면 **187장**이 됩니다. 이번 제작은 기본 원화100장으로 일단락합니다.

이 목록의 기준은 Core0.49·World1.05·러너북1.1·튜터리얼북1.1입니다. 기본 배경은 **대사만국시대**입니다. 월풍 이후는 현재 도시 그림에 섞지 않습니다. 문장·깃발의 도형과 배색은 기존 설정을 바탕으로 한 **새 시각 디자인안**이며, 이를 위해 새 국가기관·교리·능력 규칙을 만들지는 않습니다.

### 원화 수와 납품 이미지 수는 다르게 셉니다

- **원화100장**은 각각 새로 디자인하는 목록입니다. 생성 실패·수정 시도·축소본은 완료 수량에 넣지 않습니다.
- B문장11개로 **평면 깃발11종**을 만듭니다. 천의 주름이나 깃발이 펄럭이는 장면은 이후 삽화에 이 도안을 넣습니다. 국장은 투명 배경, 깃발은 실제 바탕색이 있는 평면 도안으로 구분합니다.
- E원화20개로 **장별 가로 타이틀87개**를 만듭니다. 각 장의 제목은 생성 그림에 맡기지 않고 후편집합니다. 장별 대응은 아래 표에 전부 적었습니다.
- D전신12개는 인물마다 한 장씩 독립 원화입니다. 얼굴 확대·시트 배치·실등신 키링 배치는 재사용이며, SD12개는 비율과 포즈를 새로 그리므로 별도 원화입니다.
- 문장19개와 D12개·H13개에서 고를 수 있는 굿즈 도안은 기본 **44종**입니다. 44종 전부를 후원 리워드로 제조한다는 뜻은 아닙니다. 초도에는 대표 캐릭터·동백국·러너 표식·DDOGG부터 제품군을 작게 잡을 수 있습니다.

## 공통 그림 방향

채택한 화풍은 **사람이 사는 산업 초현실주의**입니다. 끊어지는 먹선과 연필선, 넓은 과슈 색면으로 사람과 행동을 그리고, 도시와 차원에는 건조한 붓질과 깊은 공간감을 사용합니다. 작가별 참고 요소와 선·색·명암·이미지별 표현은 [삽화 화풍과 제작 규칙](17_삽화_화풍과제작규칙.md)을 따릅니다. 2026-10-10 이 화풍으로 기본 원화100장을 생성하고 자체 검토를 마쳤습니다. 전통 소재·옛 흰 건물·생활복에 크롬, 주황빛 골조, 흑공 장치가 섞입니다. 네온은 장소의 불빛으로 사용하고 모든 화면을 자주색·청색으로 덮지 않습니다. 기계 정보처리는 작고 정교한 장치로 표현하며, 모든 설비를 거대한 톱니의 증기기관으로 바꾸지 않습니다.

러너는 먼저 사람과 직업이 읽혀야 합니다. 본문에 적힌 외형·장비를 유지하고, 아직 정해지지 않은 얼굴·머리 모양·복식은 첫 전신 도안에서 잡아 이후 그림의 기준으로 사용합니다. D전신은 모두 수선골목의 **B1 현지 몸**이며, B0 본체 장면은 별도로 다룹니다. 기본 몸에 없는 거대한 임플란트나 시작 자산을 장식 때문에 덧붙이지 않습니다.

전투는 **그 차원의 물리 환경에 맞춘 현지 전투**입니다. 총격·엄폐와 높은 화력의 근접전을 모두 보여 줍니다. 아래 F16·F17 두 장을 같은 비중으로 잡고, 차원에 들어갔다는 이유로 매번 물질계 본체를 공격하는 그림으로 돌리지 않습니다.

문장은 흑백으로도 알아볼 굵은 도형을 우선합니다. 실등신 키링은 손발·장비가 잘리지 않는 닫힌 포즈로 만들고, 접속선·무기·소지품은 몸 가까이에 모읍니다. 컷아웃 이미지에는 배경 그림자나 받침 바닥을 붙이지 않습니다. 실제 고리 위치·칼선·도련·크기는 제작처 사양에 맞춰 후편집합니다.

정확한 로고·제목·상호·지도 지명·타롯 숫자·판정 수치는 원화 완성 뒤 얹습니다. 인쇄용 해상도와 제작 파일은 실제 책·제품 크기를 정한 뒤 확인합니다. 아래 목록의 비율은 구도 목표이며 생성 도구가 그대로 내보낸다는 가정은 하지 않습니다.

## 기본 원화100장의 제작 순서

아래 1–8단계의 기본 원화100장을 생성·자체 검토했습니다. D01·F01·B01을 기준으로 인물·도시·문장의 표현을 맞추고, 인물과 반복 장치를 표지·장면에서 참조했습니다. 최신 선택본은 [원화 폴더](아트워크/원화/), 수정 이전 버전은 [시안 폴더](아트워크/시안/)에 구분합니다. 비교 시안과 수정 시도는 완료 수량에 더하지 않습니다. S·L의 선택 확장20장은 이번 완료 범위에 포함하지 않습니다.

### 기본 원화100장의 완료 기준

- A–H의100번호마다 원화 한 장이 있고, 필요한 수정이 반영되어 있다.
- 러너의 얼굴·복식·장비, 국가·길드의 문장이 다른 이미지에서도 동일하게 이어진다.
- 문장19종·인물12종·H13종은 배경이 실제로 투명하며 손발·장비가 잘리지 않는다.
- 모든 선택 원화의 파일·실제 비율·투명 배경·해시와 프롬프트 연결을 확인한다.
- 이 단계는 기본 원화100장의 생성과 자체 검토 완료다.

### 원화 이후의 후편집

B문장11종의 평면 깃발 배치, E원화20종의 World77장·Core10섹션 제목 배치, 기존 FEWK 로고·타롯 숫자·본문 자막은 후편집 작업이다. 장별 대응은 이 문서의 표를 사용한다. 제조용 키링 가공과 인쇄 발주 사양도 이 단계 이후에 맞춘다. 이 파생 작업과 선택 확장20장은 현재 원화100장 완료 수량에 넣지 않는다.

## 원화100장과 별도로 준비할 편집 자료

정확한 전국 지도·권한 관계도·B0/B1/B2 몸과 연결의 도식·캐릭터시트·튜터리얼 평면도는 본문 데이터를 바탕으로 편집하는 자료입니다. AI 풍경을 정답 지도나 규칙 도식으로 쓰지 않습니다. 시나리오6편의 장소 키와 동선은 기존 원고로 작성하고 G대표 삽화와 구분합니다.

56장짜리 FEWK 전용 마이너 아르카나 덱을 실제 리워드로 만든다면 별도 카드 제작 목록이 필요합니다. 이번 H10–H13은 네 문양 원화4장입니다. 기존 문양·숫자를 배치한 간단한 플레이 덱은 편집 작업으로 만들 수 있고,56장 모두에 독립 장면 삽화를 넣는다면 **추가 원화56장**을 따로 잡습니다. Knight가 빠진52장 대체 덱과도 섞지 않습니다.

펀딩 페이지의 리워드 배열·소개 카드·목업, 캐릭터 얼굴 확대본, 문장 단색본, 스티커 시트와 포스터의 비율 변형은 기존 원화를 편집해 만듭니다. 변형 파일이 많아져도 각각을 새로 그린 이미지로 세지 않습니다.
